How I build

Models first, visuals second

Star schemas on ERP data

NetSuite saved searches, SQL and SharePoint lists shaped in Power Query into clean fact and dimension tables, with incremental refresh on the large facts.

One measure, many views

Calculation groups handle Actual, Budget, Prior Year, YTD and variance, so each report page reuses the same tested measures instead of duplicating DAX.

Secure by design

Static and dynamic row-level security, so branch managers and sales reps see only their own numbers inside a single shared App.

Fast enough to trust

DAX Studio and Performance Analyzer to find slow visuals and heavy measures before users notice them.

    SUMX ( VALUES ( DimAsset[AssetID] ), DimAsset[AvailableDays] )
RETURN
